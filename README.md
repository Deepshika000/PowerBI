# 👩‍💼 Employee Performance Analysis | Python & Power BI

📌 Project Overview

Employee Performance Analysis is an end-to-end Data Analytics project developed to analyze employee performance, workforce distribution, job roles, departmental insights, and other HR-related metrics.

The project uses Python (Google Colab) for data cleaning and preparation and Microsoft Power BI for interactive data visualization and reporting.

The objective is to transform raw employee data into meaningful business insights that can help HR teams understand workforce trends and make data-driven decisions.

 🎯 Business Objectives

- Analyze employee distribution across different departments and job roles.
- Evaluate employee performance scores.
- Understand workforce demographics based on gender and education level.
- Analyze employee performance across different categories.
- Explore employee attrition patterns.
- Examine employee promotion trends.
- Build an interactive HR dashboard to support data-driven decision-making.

 📂 Dataset Information

- Dataset: Employee Performance Dataset
- Records: 50,000 employee records retained after cleaning
- Original imported rows: 100,000
- Data preparation: Removed 50,000 completely empty rows found in the original dataset.

The dataset was inspected for missing values, duplicate records, data types, and overall data quality before visualization.

 🔄 Project Workflow

 1. Data Collection
- Imported the employee dataset into Google Colab.
- Explored the dataset structure and available columns.

 2. Data Cleaning Using Python
- Inspected dataset dimensions using `shape`.
- Checked column names and data types using `info()`.
- Identified missing values using `isnull()`.
- Checked duplicate records.
- Identified and removed completely empty rows.
- Prepared the cleaned dataset for further analysis.

 3. Exploratory Data Analysis (EDA)
- Analyzed employee distribution.
- Explored departmental and job-role patterns.
- Examined performance score distributions.
- Investigated relationships between available HR variables.

 4. Power BI Dashboard Development
- Imported the cleaned dataset into Power BI.
- Created DAX measures for analytical calculations.
- Designed interactive dashboard pages.
- Added slicers and filters for dynamic analysis.
- Used charts, KPI cards, and visual elements to present HR insights.
